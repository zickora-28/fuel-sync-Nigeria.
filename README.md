 Fuel-Sync Nigeria 🇳🇬

A community-driven platform to track fuel availability and fair pricing across Nigeria.**

  Project Overview
In many parts of Nigeria, information asymmetry regarding fuel prices and queue lengths leads to lost time and inflated costs for citizens. {Fuel-Sync} is a lightweight, frontend solution designed to bridge this gap through crowdsourced data.

  Features
Real-time Reporting: Users can instantly post price and queue updates for local filling stations.
  Mobile-First Design: Optimized for low-bandwidth environments and quick access on mobile devices.
  Transparency: Provides a clear view of the "Recent Reports" feed to help users make informed decisions before traveling to a station.

  Tech Stack
HTML5  Semantic structure for accessibility.
CSS3: Custom styles with a focus on Nigerian brand colors and responsive card layouts.
JavaScript (Vanilla):  Direct DOM manipulation for high performance without heavy frameworks.

 How to Use
1. Open the live link (add your GitHub Pages link here).
2. Enter the Station Name, the current price per litre, and the queue status.
3. Click "Share Update" to add it to the community feed.

 Social Impact
This project aims to promote economic transparency and help citizens navigate resource scarcity through collaborative technology.
